# 🚀 TaskFlow - منصة إدارة المشاريع والمهام الذكية

TaskFlow هو تطبيق ويب عصري متكامل لإدارة المشاريع وفرق العمل والمهام، مبني بأحدث تقنيات الويب (React 19, Vite, Tailwind CSS v4, Firebase Firestore & Authentication, Lucide Icons, Playwright).

---

## 🌟 أبرز المميزات (Key Features)

### 1. إدارة متكاملة للمشاريع والمهام
- إنشاء وتعديل وحذف المشاريع وتحديد أولوياتها وتواريخ استحقاقها.
- إضافة المهام مع تفاصيل دقيقة (المسؤول، الأولوية، تاريخ الانتهاء، الوصف).
- **العرض على شكل لوحة (مع السحب والإفلات Drag & Drop)**: نقل المهام بسلاسة بين (قيد الانتظار To Do، قيد التنفيذ In Progress، والمكتملة Done).
- **عرض القائمة (List View)**: عرض جدولي منظم للمهام مع الفلترة حسب الحالة والمشاريع والمهام المتأخرة.

### 2. نظام الدعوات والصلاحيات المتقدم
- دعوة الأعضاء للمشاريع عبر البريد الإلكتروني.
- وصول إشعار دعوة أنيق داخل **أيقونة جرس التنبيهات حصراً** دون تشويش أو بنرات مزعجة.
- إمكانية قبول أو رفض الدعوة مع تحديث فوري لصلاحيات الوصول.
- حماية الصلاحيات: تعديل حالة المهمة مقصور على منشئها أو العضو المسندة إليه أو مالك المشروع.

### 3. إدارة الحسابات المتعددة على نفس الجهاز (Multi-Account Switcher)
- حفظ الحسابات الموثوقة محلياً على المتصفح (حسابات Google، Facebook، والبريد الإلكتروني).
- نافذة منبثقة تفاعلية للتبديل الفوري بين الحسابات بنقرة واحدة ودون الحاجة لإعادة كتابة كلمة المرور.
- عرض قائمة الحسابات السابقة على شاشة تسجيل الدخول للوصول السريع.

### 4. التخصيص الكامل للمظهر والثيمات (Themes & Typography)
- **النمط الداكن والفاتح (Dark & Light Mode)** مع حفظ التفضيل تلقائياً.
- **6 ثيمات ألوان تمييز حقيقية (Accent Colors)**:
  - رمادي زنك (Zinc)
  - أزرق محيطي (Ocean Blue)
  - أخضر زمردي (Emerald Green)
  - بنفسجي ملكي (Royal Violet)
  - برتقالي كهرماني (Amber Orange)
  - وردي عصري (Rose Pink)
- **اختيار نوع الخط (Typography)**:
  - خط تجوال (Tajawal)
  - خط كايرو (Cairo)
  - خط إنتر (Inter)
- **التحكم بحجم الخط (Font Sizing)**: صغير (14px)، متوسط (16px)، كبير (18px).
- **المؤثرات الصوتية التفاعلية**: رنين صوتي ناعم عبر Web Audio API عند إنجاز المهام.
- **وضع العرض المكثف (Compact Mode)**.

### 5. دعم كامل للغتين العربية والإنجليزية والتصميم المتجاوب (Responsive)
- واجهة كاملة الاتجاهين (RTL / LTR).
- تصميم متجاوب 100% يعمل بكفاءة على الهواتف والأجهزة اللوحية والشاشات الكبيرة مع قائمة جانبية منزلقة للموبايل (Mobile Drawer).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 19, React Router v7, Vite.
- **Styling**: Tailwind CSS v4, Glassmorphism, Google Fonts.
- **Backend & Auth**: Firebase Firestore & Firebase Authentication.
- **Icons**: Lucide React.
- **Testing**: Playwright End-to-End Automation Testing.

## 🚀 طريقة التشغيل محلياً (Getting Started)

1. **تثبيت الحزم**:
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير**:
   ```bash
   npm run dev
   ```

3. **بناء المشروع للإنتاج**:
   ```bash
   npm run build
   ```

4. **تشغيل الفحص الآلي الشامل (E2E Tests)**:
   ```bash
   node e2e_advanced_features_test.cjs
   ```
